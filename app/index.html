About

index.html works standalone — open the file directly and everything works fully offline, no server. Served over https (e.g. GitHub Pages), it's also installable as a real app (manifest.json + service-worker.js alongside it enable "Add to Home Screen"/"Install"). All data stored locally in IndexedDB with a localStorage mirror. No account, no server-side code, no network calls.
